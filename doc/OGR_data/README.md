根据对 OGR_data.csv 数据集的分析，该数据集共收集了 **422** 个精细组装的基因组。以下是关于所使用物种及相关组装质量的数据分析：

### 一、 物种组成 (Species Composition)

数据集中主要使用了以下两个稻属物种：
1. **栽培稻 (Oryza sativa)**：共 **257** 个基因组 (占比 60.9%)
2. **野生稻 (Oryza rufipogon)**：共 **165** 个基因组 (占比 39.1%)

---

### 二、 基因组组装质量数据分析 (Data Analysis)

对两个物种的各项关键组装指标（过滤掉 `Unknown` 缺失值后）进行了统计分析，结果如下：

#### 1. 基因组总长度 (Total Length, bp)
* **野生稻 (Oryza rufipogon)**:
  * 平均长度：~403.26 Mb ($403,255,102$ bp)
  * 中位数：~404.43 Mb
  * 范围：336.62 Mb - 454.87 Mb
* **栽培稻 (Oryza sativa)**:
  * 平均长度：~388.54 Mb ($388,538,514$ bp)
  * 中位数：~390.90 Mb
  * 范围：348.27 Mb - 490.15 Mb
* **分析**：野生稻的平均基因组大小略大于栽培稻，这与野生稻通常含有更多转座子和重复序列的生物学特征相符。

#### 2. 组装连续性 (N50, bp)
* **野生稻 (Oryza rufipogon)**:
  * 平均 N50：~33.28 Mb
  * 中位数 N50：~33.24 Mb
  * 范围：27.20 Mb - 38.67 Mb
* **栽培稻 (Oryza sativa)**:
  * 平均 N50：~31.70 Mb
  * 中位数 N50：~31.75 Mb
  * 范围：25.80 Mb - 37.48 Mb
* **分析**：两者的 N50 中位数均在 30 Mb 以上，表明该数据集收集的基因组均达到了染色体级别的极高组装质量。

#### 3. 基因组完整度 (BUSCO, %)
* **野生稻 (Oryza rufipogon)**:
  * 平均完整度：**99.73%** (中位数 99.8%)
  * 范围：97.0% - 99.9%
* **栽培稻 (Oryza sativa)**:
  * 平均完整度：**99.76%** (中位数 99.9%)
  * 范围：93.3% - 99.9%
* **分析**：两者的 BUSCO 完整度极高（平均值均在 99.7% 以上），说明基因区组装非常完整。

#### 4. 缺口数量 (Gap Number)
* **野生稻 (Oryza rufipogon)**:
  * 平均 Gap 数：55.07 个 (中位数 29.0 个)
  * 范围：0 - 2,490 个
* **栽培稻 (Oryza sativa)**:
  * 平均 Gap 数：123.94 个 (中位数 40.0 个)
  * 范围：0 - 4,473 个
* **分析**：野生稻的平均 Gap 数量少于栽培稻，且两者均有实现 **0 Gap (T2T, Gap-free)** 的完美组装样本。

#### 5. 端粒数量 (Telomere Count)
* **野生稻 (Oryza rufipogon)**:
  * 平均端粒数：17.97 个 (中位数 19.0 个)
  * 范围：5 - 23 个
* **栽培稻 (Oryza sativa)**:
  * 平均端粒数：14.20 个 (中位数 14.0 个)
  * 范围：0 - 24 个
* **分析**：水稻有 12 条染色体，理论上完全组装的 T2T 基因组应含有 24 个端粒。野生稻的端粒检出率（中位数 19）略高于栽培稻（中位数 14），表明野生稻组装在染色体末端的完整性上表现优异。
