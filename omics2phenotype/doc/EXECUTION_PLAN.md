# 多组学建模代谢物定量预测 — 横向对比执行方案（一期）

> 版本：v0.1（2026-09-01）
> 范围：**不考虑组织特异性与环境条件**，只评估模型"多组学→代谢物"的建模能力，并与传统方法横向比较。
> 关联文档：`README.md`（项目定位）、`README_AGENT.md`（修订版框架）、`doc/data.md`（数据调研）

---

## 1. 研究设计与假设

### 1.1 一期目标

在**单一组织 × 单一生长条件**的数据切片上，回答一个核心问题：

> **大模型（基模）加持的多组学联合建模，相比传统统计/ML/DL 方法，预测水稻代谢物定量的能力强在哪、强多少？**

### 1.2 待验证假设（对应消融设计）

| 编号 | 假设 | 对应比较 |
|------|------|----------|
| H1 | 多组学联合（G+T）优于任何单组学（G-only / T-only） | 输入消融：`G` vs `T` vs `G+T` |
| H2 | 基模 embedding 优于传统离散 SNP 编码（0/1/2） | 编码消融：`SNP矩阵` vs `基模embedding` |
| H3 | 先验通路网络注入进一步提升精度/鲁棒性 | 结构消融：`MLP头` vs `Pathway约束头` |
| H4 | 最优模型的归因可重新命中已知位点/基因（定位能力） | 附加评估：ISM 归因 vs 已报道基因 |
| H5（二期） | **基因库+query 检索能泛化到训练时未见过的代谢物（共通性）** | 结构消融：`预设Gm/变体A,B` vs `基因库+query/变体C` + 未知代谢物留出 |

**H1 是地基**：若多组学不显著优于单组学，整个项目前提不成立，需先回去验证数据/切片合理性。设计上保证 H1 最先出结果。

### 1.3 范围边界（明确不做）

- ❌ 不建模组织差异（只用单组织，不做跨组织迁移）
- ❌ 不建模环境/处理差异（只用正常/对照条件，盐胁迫数据搁置）
- ❌ 不做单细胞（远期）
- ❌ 不引入 G×E 交互

## 2. 数据协议

### 2.1 第一步（M0）：数据盘点与配对核验 ⭐

> 本方案的数据依赖于配对核验结果，**M0 必须先于一切方法实验**。

**本地候选数据清单**（`doc/shang_data.md` 记录的商连光团队数据）：

| 数据 | 位置/规模 | 一期角色 |
|------|-----------|----------|
| `251.SNP.vcf.gz` / `251.SV.vcf.gz` | `/mnt/rice/data/Lianguang_shang/` | 基因组 G |
| `NH材料代谢组表型.xlsx` | `ai4research/doc/shang_data/` | 代谢组 M |
| 404 样本根转录组（CK/ST） | `/mnt/rice/data/Lianguang_shang/根系转录组数据/` | 转录组 T（根） |
| 叶片低氮胁迫转录组 / 叶片甲基化 | 同上级目录 | 备用（甲基化 M 一期可不入） |
| 已知盐胁迫响应基因 xlsx、mGWAS 已报道基因 | `doc/shang_data/` | H4 的外部真值验证集 |

**核验动作（输出一份 `data_inventory.md`）**：
1. 逐行读 4 个 xlsx，列出：材料编号体系（NH 编号 ↔ 251 VCF 样本名 ↔ 转录组目录名）如何对应；
2. 统计 G / T / M 三组学**全配对的样本数**（这是实验真正的 N，目标 ≥ 150，若不足需扩充数据源）；
3. 确认代谢组表型的组织与处理条件字段（是否含根/叶、CK/ST 列），圈定"单组织×单条件"的最大子集；
4. 确认 VCF 的坐标/参考基因组版本（决定下游窗口切片用的 fasta）。

### 2.2 数据切片定义（M1）

```
选取规则：
  组织：优先"叶片"（若根系配对更全则用根系，选配对最全的那个）
  条件：正常/对照（CK）
  样本：G ∩ T ∩ M 全配对的个体
最终矩阵：
  G: N × P_snp
  T: N × P_gene
  M: N × P_met（目标 Y）
```

### 2.3 各组学矩阵构建与归一化协议

**基因组 G（SNP 矩阵路线）**
- 质控：MAF ≥ 0.05，missing ≤ 10%（样本位点双过滤），保留多态位点；
- 编码：SNP 0/1/2（参考等位基因剂量），缺失用均值填补；
- 可选 LD 修剪（r² > 0.8 窗口剪）控制维度，**但保留一套未修剪版本**（大模型吃序列，SNP 矩阵吃修剪版，避免尺度不公平）；
- 协变量：前 5~10 个 PCA 作为固定效应（控制群体结构）。

**基因组 G（基模 embedding 路线）**
- 个体特异序列窗口：取目标代谢物相关基因（见 §3.7.2）TSS ± 2kb（上游启动子 + 首外显子）及基因体区域，注回个体 SNP 生成个体 FASTA；
- 版本要求：VCF 坐标 + 参考基因组 + 注释 GFF 三者一致。

**转录组 T**
- 表达定量：TPM/CPM（已有则为现成），过滤低表达基因（如 ≥10% 样本 TPM>1）；
- 变换：log2(TPM+1)（或秩变换）；
- 协变量校正：可选 regress out 批次/PCA 成分（**但要保留原始版用于对照**，避免无意识抹掉真实信号）。

**代谢组 M（目标 Y）**
- 缺失：>50% 缺失的代谢物剔除；其余按最小值填补后 log 变换（或分位数归一化）；
- 尺度：模型内部统一 z-score 或按遗传力分析用的原始尺度备份；
- 遗传力估计：`GCTA --reml` 或 `rMVP` 对每个代谢物估 h²，供 §4.3 分层。

### 2.4 数据划分协议（命门）

- **按品种划分，严禁随机行划分**：训练品种完全不可见于测试（防样本泄露导致假阳性）；
- 比例：70% 训练 / 15% 验证 / 15% 测试（或 5 折交叉验证 × 3 次重复，取折间独立的品种划分；推荐**重复嵌套划分**：多次随机品种分组求稳定）；
- 所有方法共用同一划分（保存 `partition.json`），保证横向公平。

## 3. 方法与实现细节

> 所有方法统一实现于 `src/methods/`，统一 I/O 接口（读矩阵 → 训练 → 输出预测 CSV），统一评估脚本调用。

### 3.1 传统统计谱系

| 方法 | 输入 | 实现 | 关键点 |
|------|------|------|--------|
| BLUP（个体随机效应） | M 目标 | R `lme4`/`rrBLUP` | 无信息量的最低天花板 |
| 单性状 GBLUP | G SNP 矩阵 | R `rMVP::MVP.BLUP` / `BGLR` | 默认高斯核或线性核 |
| 多组学 GBLUP | G、T、G+T 三变体 | R `BGLR`（多核 RKHS） | 核矩阵：G 核、T 核、G+T 加权核；T 核用表达矩阵的基因型相关 |
| 多性状/单性状混合 | G + T 协变量 | `BGLR` / `sommer` | 把 T 前三 PC 作为协变量进 GBLUP（简单多组学变体） |

### 3.2 经典机器学习

| 方法 | 输入 | 实现 | 超参初值 |
|------|------|------|----------|
| Elastic Net | G/T/G+T | `sklearn.linear_model.ElasticNetCV` | α 网格 1e-3~1e2，l1_ratio [0.1,0.5,0.9] |
| PLSR | G/T/G+T | `sklearn.cross_decomposition.PLSRegression` | 成分数 5~50 CV 选 |
| 岭回归 | G/T/G+T | `sklearn` | 与 BLUP 类同，作公平对照 |
| XGBoost | G/T/G+T | `xgboost` | n_estimators 500~2000, lr 0.01~0.05, max_depth 3~6；早停于验证集 |
| 随机森林 | G/T/G+T | `sklearn.ensemble` | n_estimators 1000，特征重要性顺带定位线索 |

> ML 全部在验证集上选择超参，再报告测试集；feature importance / SHAP 输出留作 H4 辅助证据。

### 3.3 深度学习基线

| 方法 | 实现要点 |
|------|----------|
| NetGP 风格（网络先验 DL） | 基因网络（RiceNet/WGCN 先验）作为邻接矩阵，图卷积读出 + MLP 头；输入 T（+G） |
| DNNGP 风格 | 多路输入（SNP 矩阵 + 表达矩阵）拼接/分离编码 → MLP → 输出；Dropout + weight decay 防过拟合 |
| VAE + MLP | T 先训 VAE（N=202 足够，瓶颈 64~128 维），瓶颈向量 + G 特征 → MLP 预测 M |

> DL 统一：PyTorch，AdamW，early stopping，batch = 全批量（样本少），重复 5 次 seed 取均值。

### 3.4 大模型路线（主推）

**3.4.1 基模选型**

| 基模 | 理由 | 角色 |
|------|------|------|
| **OGR（水稻 1.25B MoE）** | 水稻特化、已有 DNA→RNA 验证（PCC≈0.94）、本地可跑 | **主模型** |
| BOTANIC-0 / Nucleotide Transformer | 泛物种对照 | 对照模型（可选，算力允许再跑） |

**3.4.2 特征提取协议（冻结基模，不微调）**

```
输入构造（每个个体 × 每条通路基因）：个体 FASTA（TSS±2kb + 基因体）
  → OGR 逐窗口 forward（8k 窗口，滑动/截断）
  → 取 last_hidden_state → 按窗口平均池化 → 基因级 embedding (d=1024)
  → 按"代谢物-基因"先验表进行组合：
     每条代谢物对应的 k 个关键基因 embedding 拼接/注意力池化
     → 样本级特征 X_dna ∈ R^d
RNA 表达向量（同批基因表达量 log2）→ 低维投影 → X_rna ∈ R^d'
```

- 窗口策略：优先 **TSS ± 2kb**（启动子调控区）+ 基因体，突变影响表达最常见的区域；
- 每代谢物的基因集合来源：KEGG 水稻通路 + 已报道 mQTL 基因 + (可选) WGCN 共表达 top 邻居——见 §3.4.4 先验设计。

**3.4.3 回归头**

```
X_dna ⊕ X_rna → 拼接 → MLP（256 → 128 → 1，ReLU/SiLU，Dropout 0.3）
  → 每代谢物一个输出头（多任务）或逐代谢物独立训练（N 小，先逐代谢物更稳妥）
```

- 损失：MSE on z-score 后的 log-M；可选 Huber 增强鲁棒性；
- 防过拟合：冻结基模 + 小回归头 + 强 dropout + L2。

**3.4.4 先验通路注入（H3）**

- 方案：构造"代谢物子图"（代谢物节点 + 其 KEGG 通路基因节点 + 反应边），基因特征做节点特征，**浅层 GAT/GraphConv（1~2 层）**甚至简化为 **pathway-masked attention**（同一通路基因之间才能交互）；
- 对比：`纯 MLP（无先验）` vs `GAT/Pathway 头（有先验）`；
- 网络先验来源（公共/可落地）：RiceNet（水稻基因网络）、KEGG 水稻通路（ory）、MapMan、自建 WGCN（404 根转录组可自训）。

### 3.5 消融矩阵（全表）

| 方法 \ 输入 | G（SNP） | T | G+T | G（基模emb） | G(emb)+T | 备注 |
|---|---|---|---|---|---|---|
| BLUP | ✔ | — | — | — | — | H1 参照 |

## 4. 评估协议

### 4.1 重复与划分
- 品种级划分 × 3 次重复（不同种子），**任何单点数字不算数，只报告均值±sd**。

### 4.2 指标（代谢物级，全部逐代谢物计算再汇总）
- 相关：Pearson（log 空间）、Spearman；
- 量级：R²（预测 vs 实测）、RMSE、MAE；
- 汇总形式：**跨代谢物均值±sd + 中位数**，避免个别代谢物主导。

### 4.3 遗传力分层（关键加分项）
- 按 GCTA/rMVP 估计的 h² 分三层（高 >0.5 / 中 0.2~0.5 / 低 <0.2）；
- 每层分别报告各方法指标 → 证明"方法优势到底来自遗传力高的照样做得好，还是能把低遗传力的也做起来"。

### 4.4 显著性检验
- 同一切分下，方法 A vs B 在全部代谢物上的成对指标差 → paired t-test / Wilcoxon；
- 汇报：胜出方法在多少比例代谢物上胜出（win rate）——比均值更能抗 outlier。

### 4.5 定位能力评估（H4，附加但重要）
- **ISM 归因**：对最优模型，逐位点替换个体序列（参考 vs 个体等位），测预测变化，合成"影响图谱"；
- **命中率**：影响图谱 top 位点 vs 已知耐盐/mQTL 基因 5kb 内重叠率（使用 `已知盐胁迫响应基因.xlsx`、`mGWAS 定位已报道基因` 清单作 ground truth）；
- **与 mGWAS 一致性**：模型归因最强位点与文献 mQTL 峰重叠（550kb 窗口）的召回率；
- 若 H4 显著成立 → 为"预测模型可反哺定位"提供实证，这是论文第二条主线。

### 4.6 未知代谢物泛化实验（H5，二期）

> 直接回答"通用性"：训练时留出部分代谢物，测试能否预测这些**没见过**的代谢物。

- **留出方案**：随机留出 10~20% 代谢物（推荐先随机，能说明"可检索"）；二期/三期再试结构异质类留出（全新通路）。
- **未知 query 来源**：Morgan 指纹 → MLP 投影；KEGG 通路 embedding；类别 one-hot（对比三个的表征质量）。
- **判据**：留出代谢物的 Pearson/Spearman 显著优于随机基线，与"已知代谢物精度差"作为主结果；并报告 query 检索到的基因与已知 mQTL 基因的重叠（可解释性）。
- **与预设 G_m 对比**：同代谢物在变体 A/B（见过）vs 变体 C（没见过）的精度差，量化"硬编码先验 vs 模型检索"的代价与收益。

## 7. 风险与预案

| 风险 | 影响 | 预案 |
|------|------|------|
| 配对样本 < 150 | H1 统计功效不足 | 扩数据源（华农 529/533 公开矩阵、罗杰 Rice210），或降为多数据集联合验证 |
| 代谢物遗传力普遍低 | 所有方法都差 | 先做遗传力分布检验；若系统性低则重新审视代谢组定量质量/批次校正 |
| OGR 基模对代谢相关区域表征弱 | H2 不成立 | 换 BOTANIC-0 对照；或放弃"序列侧"优势，叙事转向 RNA+通路侧 |
| 品种划分重复间方差过大 | 结论不稳 | 增加重复次数/采用嵌套 CV，报告方差；必要时并数据集 |
| 已知基因 ground truth 不完整 | H4 命中率失真 | 放宽为"文献 mQTL 峰重叠+GO 富集"双口径报告 |
| **代谢物必须预设基因集（通用性瓶颈）** | 未知代谢物无法建模，通用性不足 | 一期结论限定"有先验基因集的代谢物"；二期变体 C（基因库+query 检索）从架构上解耦；冷启动用数据端补 G_m（KEGG/共表达/结构相似迁移） |
