**关键观察**：
- 越稀有的变异越多：AF<0.01 合计占 44.5%，呈现典型的选择/漂变负偏分布
- AF<0.005 的极稀有变异占比最大（35.7%），其中包含 **singleton（AC=1）4,310,396 个 SNP**（占全部 SNP 的 14.6%）和 1,017,021 个 indel
- Ts/Tv 随 AF 升高而升高（0.07→2.07, 0.5–1.0→2.54），符合"低频变异更多转捩（transversion）富集于新突变，高频变异经选择富集转换（transition）"的经典图式

## 7. Indel 长度分布（IDD）

- 范围覆盖 −60 … +60 bp（整数长度），**长度 +60 处有显著堆积（143,470 位点）**，−60 处也有 40,804 位点——两端截断簇可能反映超长缺失/插入被统一截断标注，或同源/端粒区域集中产生的极端变异；建模时应警惕这批位点（可能为结构变异或组装假象）
- 长度-2/-1 附近的正负小 indel 占多数（与测序/比对误差方向一致，需结合真实变异做判定）
- 与 `251.SV.vcf.gz`（1.7G，结构变异）互补：本文件是短变异（SNV/indel），SV 单独文件

## 8. 深度分布（DP）

- 深度 1–7 的位点占比极低（合计 <0.4%），说明低覆盖基因型位点极少，数据质量高
- 深度 ≥8 的位点占绝大多数（见 depth_dist.csv）
- 平均/中位深度建议后续用 `bcftools query -f '%DP'` 单独统计（stats 默认分档 1–500）

## 9. 对下游（变异感知预训练 / 变异注入）的含义

1. **窗口内变异密度估算**：33.9M 变异 / 水稻基因组 ~373M bp（12 染色体）≈ **0.091 /bp，即平均每 11 bp 一个变异位点**。对 32k 窗口（GenOmics 训练窗口）平均约 3,000 个变异位点；对 1M 窗口约 91k。用 VCF 作为输入给模型训练时，若按"变异位点+参考碱基"编码，token 序列会显著变长——需要稀疏/列式编码（如 GenVarLoader 的单倍型序列生成，或"差异编码"）。
2. **singleton 占比高**（14.6% SNP 为 AC=1）：低频率碱基替换噪声/新突变多，训练时若按样本逐个体调用，多数差异位点样本特异性极强，容易过拟合"稀有等位基因"记忆。可考虑用 AF 分箱加权或过滤 AC=1 特定位点。
3. **Ts/Tv 模式**：转换富集说明变异谱有生物学偏好，模型如果见过足够的参考基因组应该能学到碱基上下文依赖——变异感知预训练应保持参考上下文 + 变异标记，而不是把变异当独立 token。
4. **13.54% 多等位位点**：VCF→单倍型序列（GenVarLoader 方式）时，多等位位点可自然分配到不同单倍型；若用"变异列表"编码则需设计 ALT allele 索引。
5. **质检建议**：QUAL 阈值建议 ≥30（丢弃 <30 的极少数位点），DP 过滤建议 ≥5 或按样本十分位——本数据集大部分位点远超阈值，对建模影响不大，主要为下游效率和内存考虑。

原始命令（可复现）：

```bash
BCF=/mnt/rice/default/Workspace/xuxiaolong/mamba/envs/tools/bin/bcftools
$BCF stats /mnt/rice/data/Lianguang_shang/251.SNP.vcf.gz > bcftools_stats.txt 2> bcftools_stats.err
$BCF query -f '%CHROM\n' /mnt/rice/data/Lianguang_shang/251.SNP.vcf.gz | sort | uniq -c > chrom_counts.tsv
$BCF query -l /mnt/rice/data/Lianguang_shang/251.SNP.vcf.gz > samples.txt
python3 parse_variant_stats.py
```
