种种数据：1.与华农设计玉米多维组学benchmark方案，初步确定不小于100骨干亲本的全生育期及耐逆抗病条件下的多组织bulk转录组及单细胞RNA/ATACseq方案，年内开展小规模测试。在此基础上梳理玉米公开数据，包括：（A）群体转录组层面，503 份自交系幼苗叶泛转录组（Hirsch et al., 2014）、368 品系叶片表达-eQTL 与表达-适应度关联数据（Kremling et al., 2018）、B73 23 组织 79 样本表达图谱（Stelpflug et al., 2016）、Mo17 42 组织-发育阶段转录组（Chen et al., 2023）及籽粒发育、杂种优势等专项转录组；（B）逆境与抗病转录组层面，覆盖干旱及其复水、盐、高温、低氮、铝毒、涝渍等非生物胁迫，以及大斑病、小斑病、茎腐/穗腐病、丝黑穗病、南方锈病和玉米螟等生物逆境的多品系、多时间点、多组织 bulk RNA-seq 数据；（C）单细胞与空间转录组层面，整合多组织 scATAC-seq 顺式调控元件图谱（Marand et al., 2021）、雌穗/雄穗（Xu et al., 2021）、胚乳（Yuan et al., 2024）、茎尖分生组织（Satterlee et al., 2020; Dong et al., 2026）、根尖（Bian et al., 2025）等单细胞/单核转录组图谱、南方锈病单核+空间转录组（Wang et al., 2026）及 scMaize 多数据集整合图谱。
