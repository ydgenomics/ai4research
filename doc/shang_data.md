## Lianguang_shang — 目录结构与数据总结

该目录是 **商连光团队** (Lianguang Shang) 的 NH 材料水稻组学数据汇总，总数据量约 **5.5TB+**，主要包含以下内容：

---

### 一、根目录文件

| 文件 | 大小 | 说明 |
|------|------|------|
| `251.SNP.vcf.gz` | **36G** | 251份水稻材料的SNP变异(VCF)文件 |
| `251.SNP.vcf.gz.csi` | - | SNP索引文件 |
| `251.SV.vcf.gz` | **1.7G** | 251份材料的SV(结构变异)VCF文件 |
| `20260319-亚洲栽培稻表型数据-贺慧英-商连光组.xlsx` | 424K | 亚洲栽培稻表型数据 |
| `20260319-已知盐胁迫响应基因-贺慧英-商连光组01.xlsx` | 16K | 已知盐胁迫响应基因列表 |
| `20260320-已知氮代谢基因.xlsx` | 512K | 已知氮代谢基因列表 |
| `NH材料代谢组表型.xlsx` | 11M | NH材料代谢组表型数据 |
| `商连光团队 NH材料组学数据及表型清单整理-贺慧英.xlsx` | 112K | 组学数据及表型清单总表 |
| `硬盘中材料对应编号表.xlsx` | 40K | 材料编号对应表 |
| `leaf_nitro.log` | - | 叶片氮相关log文件 |
| `叶片低氮胁迫转录组数据.tar` | - | 叶片低氮胁迫转录组打包文件 |

---

### 二、子目录详情

#### 1. `根系转录组数据/` — **2.7T** ⭐ 最大数据块
- **404个样本**，每个样本一个子目录
- 命名规则：`CK***`（对照）和 `ST***`（处理）两种前缀
- 每个样本包含：
  - `{样本ID}_1.clean.fq.gz` (R1端)
  - `{样本ID}_2.clean.fq.gz` (R2端)
  - `MD5.txt` (校验文件)
- 包括部分带 `-1` 后缀的重复样本（如 `CK045-1`, `ST003-1`）

#### 2. `02低氮数据补充/` — **834G**
- 包含 `LN_complement.tar` 低氮补充数据压缩包
- 附带 `md5.txt` 和 `Note.txt`

#### 3. `叶片甲基化数据/` — **1.4T**
- **19份非洲稻WGBS clean data** (打包为tar)
- 大量 `MH***.fq.gz` 双端测序文件（MH编号样本）
- 部分 `CW*` 前缀样本（如 `CW01_L2`）

#### 4. `202Os-GWAS/` — **213M**
- **142个表型性状**的GWAS分析结果（PD001~PD142+）
- 每个性状包含：
  - `PDxxx_signals.txt` — 显著信号位点
  - `PDxxx_QQplot.p_wald.jpg` — QQ图
  - `PDxxx_Rect_Manhtn.p_wald.jpg` — 曼哈顿图

#### 5. `251基因注释文件/` — **985M**
- `251_Ref_gff_chr.tar.gz` — 251份材料参考基因组注释文件(gff格式)压缩包

#### 6. `LN/` — 4.0K
- 含 `LN.md5.txt` 校验文件

#### 7. `mGWAS定位已报道基因/` — **119M**
- `mGWAS定位已报道基因` 子目录，包含已报道的mGWAS定位基因相关数据

#### 8. `叶片盐胁迫转录组数据/` — **80K**
- 包含 `leaf_salt_md5.txt`、`材料对应NH编号.xlsx` 和 `ShangPublic` 目录/文件

#### 9. `.history/`
- 隐藏的历史记录目录

---

### 三、数据整体概览

| 数据类别 | 规模 | 说明 |
|---------|------|------|
| **根系转录组** | **2.7T** / 404样本 | 最大数据集，CK/ST双端clean reads |
| **叶片甲基化(WGBS)** | **1.4T** | 19份非洲稻 + MH系材料 |
| **低氮补充数据** | **834G** | LN_complement.tar |
| **SNP变异数据** | **36G** | 251份材料的VCF |
| **SV变异数据** | **1.7G** | 结构变异VCF |
| **GWAS结果** | **213M** / 142性状 | 含信号、QQ图、曼哈顿图 |
| **基因注释** | **985M** | 251份材料gff注释 |
| **mGWAS定位基因** | **119M** | 已报道基因相关数据 |
| **表型/代谢组** | ~12M | 多份xlsx表格 |
| **盐胁迫转录组** | 80K | 清单/编号文件 |

**数据特点总结**：该目录是商连光团队围绕 **251份水稻NH材料** 构建的多组学数据库，覆盖 **基因组变异(SNP/SV)**、**根系转录组**、**叶片甲基化**、**低氮胁迫**、**盐胁迫**、**GWAS分析** 及 **代谢组表型**，是进行水稻功能基因组学和关联分析的重要数据资源。
