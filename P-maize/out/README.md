## 玉米公开组学数据集 — 总结

### 1. 数据规模
| 指标 | 数量 |
|---|---|
| SRA Run 行数（无重复） | **57,298** |
| 唯一 BioSample | 49,535 |
| 唯一 BioProject / SRAStudy | 1,802 / 1,813 |
| BioProject 汇总表 | 1,523 个项目，9 列 |

### 2. 组成结构
- **组学类型**：Bulk RNA-seq **53,096（92.7%）** 占绝对主导；Single-Cell/Spatial 2,617；ATAC-seq 529；ChIP-seq 62；另有少量多组学组合标签
- **平台**：Illumina 最多（54,889），其余为 DNBSEQ 504、PacBio 163 等
- **物种纯度**：`Zea mays`（TaxID 4577）55,638（97.1%）；混入 `subsp. mays`（381124）1,549（约 2.7%），需过滤
- **访问控制**：100% public，全部可直接下载

### 3. 数据量（去重后全量）
- 总碱基 **≈310.3 Tb**，总 reads **≈1.42 T**，SRA 存储 **≈118.7 TB**，平均读长 213 bp
- 按类型：Bulk RNA-seq 贡献 273.5 Tb（88%）；Single-Cell/Spatial 9.7 Tb；ATAC-seq 7.4 Tb

### 4. 时间分布（2009–2026）
- 2017 年起明显放量；**2022–2023 年达峰**（7,061 / 7,243 条）；2024 回落至 5,066；2025 回升至 7,076；2026 年至今 3,805

### 5. 项目与文献关联
- BioProject 表中仅 **345 个（22.6%）有 GEO 号**，543 个标记为农学相关（Relevance=yes）
- Run 级可经项目回链到 GEO 的仅 **14.3%**，`Study_Pubmed_id` 大多为空 → 文献关联偏弱，需靠 BioProject Title/GEO 反查补充

### 6. 过滤结果（示例规则：`4577` + `public` + `Bulk RNA-seq` + `≥1 Gb`）
```
57,298 → 55,638 → 55,638 → 51,507 → 39,495 Run
```
- 最终 **39,495 Run / 35,769 唯一 BioSample / 1,573 项目，总碱基 ≈259 TB**
- 已导出 `out/maize_sra_filtered.csv`

### 结论与建议
- **Bulk RNA-seq 占 92%**，且 ~259 TB 深度合格（≥1Gb/样本），非常适合作为基因表达预测模型的训练语料
