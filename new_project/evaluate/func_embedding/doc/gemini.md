这是一个非常经典的多标签（Multi-label）或多值属性（Multi-valued attribute）评估问题。由于一个基因通常参与多个生物过程（BP）、具备多种分子功能（MF），因此其对应的 GO term 确实是一对多的。
在这种情况下，直接对 Embedding 进行降维（如 t-SNE）并染上单一颜色（单标签）确实不可行。不过，在表征学习和生物信息学中，有几种非常成熟的标准方法来解决非一对一标签的评估问题。
------------------------------
## 方法一：基于语义相似度的相关性分析（最推荐，无监督）
这种方法不需要降维，也不需要训练分类器，而是直接评估“Embedding 空间的距离”是否与“GO 语义空间的距离”保持一致。

* 原理：如果两个基因在 GO 标签上高度相似，那么它们的 DNA Embedding 也应该非常相似（余弦相似度高）。
* 具体步骤：
1. 计算 GO 语义相似度矩阵：利用 R 包 GOSemSim 或 Python 库，使用 Wang 算法 或 Resnik 算法 计算基因两两之间的 GO 语义相似度 $S_{GO}(G_i, G_j)$（范围通常在 0 到 1 之间）。这些算法会自动考虑 GO 的树状层级结构和多标签重合度。
   2. 计算 Embedding 相似度矩阵：计算对应的 DNA Embedding 两两之间的余弦相似度 $S_{Emb}(G_i, G_j)$。
   3. 评估指标（Mantel Test / Spearman 关联）：计算这两个对称矩阵之间的 Spearman 秩相关系数。相关系数越高，说明模型对功能的表征能力越强。

## 方法二：多标签分类下游任务预测（有监督/半监督）
这是机器学习中评估 Embedding 质量最通用的 Benchmark 方法。不看图像怎么聚类，而是看 Embedding 作为特征时，下游分类器能学得有多好。

* 具体步骤：
1. 将全基因组数据划分为训练集和测试集（例如 80% / 20%）。
   2. 输入：基因的 DNA Embedding。
   3. 输出：一个 0/1 的多标签向量（向量长度为选定的 GO term 总数，基因拥有的 GO 位置为 1，其余为 0）。
   4. 下游模型：接一个简单的线性层或支持向量机（SVM），使用多标签分类损失（如 BCEWithLogitsLoss）。
   5. 评估指标：在测试集上计算 Micro-F1 score、Macro-F1 score 或 mAP (Mean Average Precision)。指标越高，说明 Embedding 中包含的功能信息越丰富。

## 方法三：基于特定高频核心标签的“单标签化”过滤（用于可视化降维）
如果您必须通过 t-SNE 或 UMAP 降维画出直观的聚类图，可以通过对数据进行“清洗和精简”来强行构建一对一关系。

* 具体步骤：
1. 筛选不相交的核心通路：在水稻中挑选 3-5 个互不重叠、背景明确的核心生物学通路（例如：光合作用、细胞壁合成、抗病响应）。
   2. 严格过滤基因：只保留仅属于这几个通路之一的基因，剔除同时参与多个通路的“兼职”基因。
   3. 降维可视化：此时，每个基因就变成了一对一的单标签，可以直接进行 t-SNE 降维并根据通路染色，观察模型是否能把这几个核心通路在空间上明确分开。

## 方法四：原型网络（Prototype）与距离度量
评估每个 GO term 在 Embedding 空间中是否有内聚性。

* 具体步骤：
1. 对于某一个具体的 GO term（如 GO:0009651），找出所有包含该标签的基因。
   2. 计算这些基因 Embedding 的平均值，作为该 GO term 的原型向量（Prototype Vector）。
   3. 评估指标：计算属于该 GO 标签的基因到该原型的平均距离，与随机基因到该原型的平均距离进行对比（可以使用 Davies-Bouldin Index 或 Silhouette Score 的变体）。如果属于该标签的基因离原型显著更近，说明模型成功表征了该功能。

## 💡 针对水稻研究的避坑建议
水稻中有很多 电子预测（Inferred from Electronic Annotation, IEA） 的 GO 标签，这些标签本身就是靠序列相似性比对（如 BLAST）预测出来的。

* 技术建议：在提取水稻 GO 标签时，如果可以，尽量过滤掉证据码（Evidence Code）为 IEA 的标签，优先保留有实验证据（如 IMP, IGI, IDA）或同行评审（TAS）的标签。用高置信度的标签评测大模型，得出的 Embedding 表征能力结论才更具说服力。
