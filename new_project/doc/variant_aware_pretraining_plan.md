# 变异感知基模对比方案（水稻版 UKBioBERT）

> 目标：回答一个核心科学问题——**用群体变异信息继续预训练 DNA 基模，是否比直接使用现成基模（OGR）更能表征水稻的基因特征（表达、变异效应、功能）？**
>
> 方法：受控对照实验。版本 A（基模不微调）vs 版本 B（基模变异预训练），下游头与评测完全一致。
>
> 对标文献：Liu, T. et al. *Pre-training Genomic Language Model with Variants for Better Modeling Functional Genomics.* bioRxiv 2025.02.26.640468（UKBioBERT / UKBioFormer / UKBioZoi）
>
> 状态：草案 · 待决策（决策点用 ⚠️ 标注）

---

## 一、背景与问题定义

### 1.1 UKBioBERT 做了什么（对标基准）

| 要素 | UKBioBERT | 水稻版 |
|---|---|---|
| 预训练数据 | UK Biobank ~50 万个体的**变异序列**（参考基因组 + 变异打回） | 251 商连光个体 + 422 泛基因组（待定，见 §4） |
| 预训练目标 | BERT 式 MLM（双向） | ⚠️ 待定（NTP 续训 or MLM 新训，见 §3） |
| 下游接入 | 接 Enformer → UKBioFormer；接 Borzoi → UKBioZoi | 接 GenOmics（现有栈） |
| 核心卖点 | 变异感知 embedding + 改善表达预测 + ISM/eQTL 识别 | 同 —— 预测表达轨道 + ΔE 对齐 eQTL |

### 1.2 科学假设

> **H1**：在群体变异序列上继续预训练，能让基模的 hidden representation 对"变异→功能"更敏感，从而在相同下游头上取得更好的表达预测与变异效应预测。
>
> **H0（零假设）**：OGR 已在 422 泛基因组（含 165 野生稻）上预训练，其多样性知识已隐式覆盖常见变异；额外的变异继续预训练不带来增益（或边际收益无法覆盖训练成本）。

两版对比即对 H1/H0 的一次直接判决。

### 1.3 与现有资产的关系

```
现有:  OGR 1.25B (422 泛基因组 NTP) ──> GenOmics(U-Net) ──> 逐碱基表达轨道 (PCC~0.94)
目标:  用 2×2 实验矩阵（§2）系统回答 README 核心问题：
       "水稻模型建模个体表达差异的能力到底如何？"
```

## 二、总体实验设计：2×2 实验矩阵（核心）

### 2.1 两个正交维度的拆解

README 中的三个方案（方案一/二/三）实际是两个正交维度的 2×2 组合：

- **维度 X（行）**：阶段 1 是否用群体数据微调基模 —— `原始 OGR` vs `群体微调后`
- **维度 Y（列）**：阶段 2 下游训练时基模是否冻结 —— `冻结` vs `不冻结`

```
                        阶段2：基模冻结            阶段2：基模不冻结
    ──────────────────────────────────    ──────────────────────────────
原始 OGR   │  ① 探针-原始（新增）             ② baseline-端到端（现状，复用ckpt）
群体微调后 │  ③ 探针-群体微调（= README方案二）  ④ 完整路线（= README方案三）
```

| 格 | 配置 | 回答的问题 | 必要性 |
|---|---|---|---|
| ① | 原始 OGR 冻结 + 下游头 | "OGR 原始表征本身够不够" | **强烈建议补**：是"群体微调是否必要"的直接对照 |
| ② | 原始 OGR 不冻结 + 下游头 | baseline（= README 方案一） | 必做（现有 GenOmics 全参微调即此格，PCC≈0.94 可直接复用） |
| ③ | 群体微调后冻结 + 下游头 | "群体微调后表征提升多少"（= README 方案二） | 值得做：探针价值最高、省算力、可复用于多组学下游 |
| ④ | 群体微调后不冻结 + 下游头 | "群体微调是否给端到端带来增量"（= README 方案三） | 值得做：最终交付候选，但增量取决于阶段1任务（§2.4） |

### 2.2 关键对照与结论推断

| 对照 | 差值含义 | 结论推断 |
|---|---|---|
| ① vs ② | 端到端继续调基模的净贡献 | ②≫①：下游必须参与调基模；②≈①：下游头足够 |
| ③ vs ④ | 端到端在"群体微调表征"之上的增量 | ④≫③：端到端仍必要（方案三为正）；④≈③：强群体表征即可（方案三可省） |
| **① vs ③** | **群体微调本身的净增量（同一冻结条件）** | **③≫①：群体微调显著改善表征（H1 支持，核心卖点）；③≈①：H0，微调不必要** |
| ② vs ④ | 群体微调对端到端全流程的净增量 | ④≫②：两阶段路线成立（交付路线=④）；④≈②：直接基线即可 |

> ⚠️ **最关键的是 ① vs ③**：只有这一对照能直接量化"群体微调到底有没有用"——其他对照混入了"是否端到端调基模"的干扰。README 三方案恰好缺了①，必须补上。

### 2.3 公平性铁律（审稿必查）

1. 四格共用**完全相同**的下游头（GenOmics）、优化器、epoch、数据切分；
2. 按**染色体**切分训练/验证/测试，群体微调数据**不得包含测试染色体**的变异；
3. 群体微调的步数、学习率、数据配比全部记录，保证可复现；
4. 每个评测跑 ≥3 次不同种子取均值±标准差。

### 2.4 阶段 1 的"群体数据微调"是什么任务 ⚠️ 关键

方案④（= 方案三）的结果解读完全取决于阶段 1 的训练目标：

| 阶段 1 任务 | ④ vs ② 的增量来源 | 对标 | 价值 |
|---|---|---|---|
| **自监督**（个体序列 NTP/MLM） | 变异感知预训练的净增益 | UKBioBERT（本体） | 高：论文核心结果 |
| **监督**（个体表达轨道预演） | 几乎为零（同一任务预热，端到端会抵消） | curriculum 学习 | 低：与端到端差异小 |

→ 阶段 1 必须用**自监督变异感知预训练**（§3 的 B3），④ 才有论文价值。

## 三、阶段 1（群体微调）的实现选择 ⚠️ 决策点 1

> 对应 2×2 矩阵"群体微调后"这一行（③④ 两格的前置）：决策结果决定 ③④ 使用哪个基模权重。

### 架构范式对比：BERT（encoder / MLM）vs OGR（decoder / NTP）〔D1 前置依据〕

本节的 B1/B2/B3 方案实质上是两种**架构范式**的取舍，先厘清差异再谈选择。

> **一句话定位**
> - **BERT（encoder + MLM）**：双向注意力，每个位置能看到**全序列上下文**，目标是从受损输入**重建**原文；
> - **OGR（decoder + NTP）**：因果注意力，每个位置只能看**左侧**，目标是从前缀**生成**下一个。

#### 逐维度对比（对变异任务的实质影响）

| 维度 | BERT（encoder, MLM） | OGR（decoder, NTP + MoE） | 对"变异感知"的意义 |
|---|---|---|---|
| **注意力** | 双向（全序列可见） | 因果（只看左侧） | ⭐ **关键差异**：增强子-启动子长程互作、剪接位点两侧上下文，双向可见更自然；decoder 右侧不可见（对"序列语法"可能更强健，但对"位点功能上下文"受限） |
| **训练目标** | 掩码 ~15% token 重建 | 逐位点下一碱基预测 | MLM 天然支持"**掩码变异 → 预测 ref/alt**"显式目标；NTP 学生成语法，变异敏感性需靠加权/辅助损失注入 |
| **监督密度** | 每步 ~15% 位置有梯度 | 每步 ~100% 位置有梯度 | NTP 每步信息量更大；MLM 信号更稀疏但更"语义化" |
| **参数形态** | 通常 dense | **8 专家 MoE（激活 2/8）** | MoE 同 FLOPs 容量更大；但继续预训练需维持路由负载均衡 |
| **位置编码** | 绝对位置（BERT）/ RoPE（新一代） | RoPE **base=50M**（专为 1Mb 长上下文） | OGR 的长程能力是 BERT 式模型难以直接复制的 |
| **上下文长度** | 常规 512–4096 | 最高 **1Mb** | ⭐ 水稻调控是长程问题（增强子可在 100kb+），OGR 占优 |
| **下游兼容（本栈）** | `last_hidden_state [B,L,H]` 同样可用 | 现有 GenOmics 直接吃 | 两条路的下游头几乎不用改（都是 hidden state → U-Net） |
| **权重复用** | ✗ 与 OGR 不兼容，需从头训 | ✓ 直接续训 | 工程成本差距巨大 |
| **已知文献** | Nucleotide Transformer / DNABERT 系多任务领先 | Evo（decoder）擅长长序列生成与进化解码 | 两范式各有成功案例，无定论 |

#### 对"变异感知"的关键差异

- **MLM（BERT）的天然优势＝显式变异监督**：UKBioBERT 把变异位点 mask 掉 → 强迫模型从上下文预测"此处应为什么碱基" → 学会"上下文 → 等位基因/变异后果"映射。变异位点本就是最需要上下文推断的位置，mask 它等于**显式地为变异付费**，这是 UKBioBERT 选 BERT 而非 decoder 的直接原因。
- **NTP（OGR）的隐性优势＝长程 + 已有多样性**：① OGR 已在 422 泛基因组上用 NTP 学会"变异空间边界"（泛基因组=蓝图、群体=概率测度）；② RoPE base=50M 提供几十到上百 kb 的长程语境，恰是水稻增强子-启动子互作的主战场；③ 但 NTP 不会"专门盯着变异位点"，需用采样加权/辅助损失把注意力引过去。

```
                    显式变异监督          长程上下文        工程复用
    BERT (MLM)    ⭐⭐⭐⭐⭐ 天然支持       ⭐⭐ 512-4k        ✗ 从头训
    OGR (NTP)     ⭐⭐ 需加权技巧         ⭐⭐⭐⭐⭐ 1Mb      ⭐⭐⭐⭐⭐ 直接续训
```

#### 对配置选择的映射

| 目标 | 选择 | 理由 |
|---|---|---|
| 保住 OGR 资产、低成本出结果（主线路） | 方案 B3（OGR 续训 NTP + 加权采样） | 复用一个已在 422 泛基因组预训练的 1.25B 权重；长程保留；变异感知靠加权弥补 |
| 严格对标 UKBioBERT、发强对比 | 方案 B2（轻量 BERT + 变异掩码，与 OGR 双轨） | BERT 显式变异监督更优雅；但牺牲 OGR 长程与既有知识 |
| 两全其美（进阶） | OGR 续训时**叠加 decoder 版变异掩码辅助损失** | NTP 基础上加 mask 变异位点预测，近似 MLM 的显式监督，不改架构、不丢长程（见 B3 可扩展性） |

### 3.1 方案 B1：OGR 继续 NTP（decoder 续训）

| 维度 | 评价 |
|---|---|
| **工程成本** | ⭐ 低。复用 OGR 预训练框架（Megatron 5D 并行已跑通），仅换数据 |
| **权重兼容** | ⭐ 完美。直接续训，hidden 1024 不变，GenOmics 下游零改动 |
| **知识保留** | ⭐ 保留 422 泛基因组全部知识，无灾难性遗忘风险（低 LR 短训即可） |
| **学术对齐度** | ◐ 与 UKBioBERT 的 MLM 不完全对齐（NTP 是因果目标），若审稿人严格对标会被质疑 |
| **变异敏感性** | ◐ NTP 对变异位点的学习依赖"变异导致的 next-base 概率差"，敏感度低于显式掩码变异的 MLM |

### 3.2 方案 B2：另训 MLM 基模（BERT 式，严格复刻 UKBioBERT）

| 维度 | 评价 |
|---|---|
| **工程成本** | ✗ 极高。1B 级 MLM 从头训练（数据/GPU/时间），脱离 OGR |
| **权重兼容** | ✗ 与 OGR 架构不兼容（decoder causal → encoder bidirectional），GenOmics 需适配 |
| **知识保留** | ✗ 搁置 422 泛基因组预训练成果，等于浪费最大资产 |
| **学术对齐度** | ⭐ 与 UKBioBERT 完全对齐，可比性最强 |
| **变异敏感性** | ⭐ MLM 掩码变异位点，显式监督"此处变异有功能后果"，最直接 |

### 3.3 方案 B3（折中，推荐首选）：OGR 继续 NTP + 变异位点加权采样

核心思路：**不换架构，改数据分布**。

- 继续用 OGR 的 NTP 目标（tokenizer/attention/MoE 全部不变）；
- 训练数据从「参考基因组窗口」换成「**个体伪基因组窗口**」（变异打回），等价于把"变异感知"注入预训练分布；
- 对**含变异的窗口加权采样**（如 5–10×），对抗"99% 碱基与参考相同"的信号稀释；
- 低学习率（peak 1e-5 量级）短训（几千步），防遗忘。

| 维度 | 评价 |
|---|---|
| 工程成本 | ⭐ 低–中（仅改数据采样器 + 预训练脚本复用） |
| 学术对齐度 | ◐ 非 MLM，但与 UKBioBERT 的**精神**一致（用变异序列预训练） |
| 变异敏感性 | ◐ 经加权采样增强；实证上需评测② 验证是否足够 |
| 可扩展性 | ⭐ 最顺：若评测不足，可在 B3 上叠加"变异掩码辅助损失"，渐进升级为 B2 效果而不推倒重来 |

### 3.4 决策建议

| 场景 | 选择 |
|---|---|
| 主线路（推荐） | **B3**：OGR 续训 NTP + 变异加权采样。成本可控、保留资产、可渐进增强 |
| 严格对标/投稿需要 | 在 B3 基础上加**变异掩码辅助目标**（decoder 版"mask 变异位点预测"），近似 MLM 效果 |
| 不推荐 | B2 从头训 MLM，除非有充足 GPU 预算并愿意脱离 OGR（可与主线路并行作为远期对比） |

## 四、预训练数据：样本量现实与方案 ⚠️ 决策点 2

### 4.1 致命差距

| | UK Biobank | 商连光 251 | 差距 |
|---|---|---|---|
| 个体数 | 500,000 | 251 | **~2000×** |
| 变异密度(与参考) | ~0.1% | ~0.5–1% | 水稻占优 |
| LD 结构信息量 | 极丰富 | 弱 | 251 个体 LD 学习困难 |

### 4.2 缓解手段

| 手段 | 做法 | 效果 |
|---|---|---|
| **并入 422 泛基因组** | 训练序列 = 251 个体伪基因组 + 422 泛基因组（加权混合） | 多样性最大；泛基因组天然含大变异 |
| 变异窗口加权采样 | 含变异窗口 5–10× 采样 | 对抗信号稀释 |
| 用 3K RGP 扩充 | 若可用，3K 个体变异序列摊薄样本劣势（需评估下载/存储） | 样本量从 251 → 数千 |
| 转录组监督辅助 | 预训练后接下游时，只用有转录组标签的个体做监督微调 | 评测信号密度由转录组覆盖度决定（见 §8） |

> ⚠️ 修正（讨论结论）："并入泛基因组"并非单纯补样本量。**泛基因组变异**（种间/大尺度固定差异）与**群体变异**（种内 SNP/indel，带 MAF/LD 统计结构）是**两个维度**的信息——前者提供"变异空间蓝图"，后者提供"变异空间的概率测度"并天然对齐 ISM 推理分布（参考+扰动）。混合时需控制比例，避免"全新组装"的模式稀释"参考+扰动"分布的独特性；推荐 §4.3 分阶段而非无差别混合。

### 4.3 数据形态

```
① SNP/小 indel 打回参考 → 个体伪基因组（与 UKB 形态一致，兼容现有 fasta 管线）
② 422 泛基因组原有 fasta（OGR 预训练同源数据）
③ 混合策略：按 1:1~3:1 加权，含变异窗口上调采样比例
```

⚠️ 仍需确认：251 材料中各有多少份有转录组覆盖（见 §8），决定后续监督微调方案。

## 五、评测任务定义（三件套全测）

### 评测① 基因表达预测（复用现有流水线）

- 任务：单碱基 RNA-seq 轨道预测（GenOmics，逐组织×模态输出）
- 指标：碱基级 **PCC / Spearman / R²**；零膨胀 **zero-AUROC / nonzero-AUPRC**（现有 90%+ 为 0，nonzero 指标才是关键）
- 数据集：有转录组标签的材料，按染色体切分
- 判别：版本 B 在 nonzero 区域 PCC/AUROC 显著高于 A ⇒ H1 成立

### 评测② ISM 变异效应 → eQTL 对齐（UKBioBERT 式卖点）

- 任务：对候选 cis-eQTL SNP，构造 ref/alt 双窗口各推理一次，$\Delta E = E_{alt} - E_{ref}$，基因区段聚合
- 指标：
  - **方向准确率**（sign agreement，目标 ≥70%）
  - ΔE 与真实 eQTL beta 的 **Pearson/Spearman**
  - fine-mapped（PIP>0.5）子集单独评测，剥离 LD 伪信号
- 数据：引入 eQTL 标签（3K RGP 公共 eQTL 或商连光自算，见 §6）
- 判别：版本 B 方向准确率显著高于 A ⇒ 变异感知预训练确实增强变异效应表征

### 评测③ 基因功能 embedding（线性探针）

- 任务：基因 TSS ± 窗口 → backbone hidden state 平均 → 基因 embedding
- 指标：
  - 表达水平分类（高/中/低）线性探针准确率
  - 已知功能基因聚类（如盐/氮响应基因集）ARI/NMI
  - （可选）GO/通路富集可比性
- 判别：版本 B 探针优于 A ⇒ "更懂基因功能"

## 六、eQTL 标签来源（评测②的前置）

| 来源 | 优点 | 风险 |
|---|---|---|
| 3K RGP 公共 eQTL（RED/IC4R） | 现成标签、金标准清晰 | 坐标系统与 OGR/商连光对齐需 liftover；与 251 材料遗传背景不同 |
| 商连光 251 自算 eQTL | 材料一致、可直接对应用个体表达 | 需 matrix-eQTL 全套分析（变异-表达配对），工作量大；转录组覆盖度受限 |
| 混合 | 公共做基线、私有做验证 | 两套标签需统一 harmozation |

建议：**评测基线用公共 3K eQTL（快），落地验证用商连光自算 eQTL（准）**。
