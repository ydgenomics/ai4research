# omics2phenotype 大模型建模多组学数据赋能水稻代谢物的预测 

- 水稻智能育种的需求，是建模宏观（表型）与微观（分子）的关系，回到表型为什么的问题，需要去分子层面找答案、找机制。
- sequence2function model常见的是建模配对的DNA和RNA数据，类似的传统生信分析是eQTL和TWAS，回答的是序列变化和表达变化的关系，找到的是eQTL位点和eGene，这里我们认为表达的变化是表型变化的果，这个分析提供的是potential的结果。这里有个问题是，从DNA到表型需要- 经历复杂的生物学过程，可能RNA有差异，但是在蛋白/代谢并没有表现出差异，所以我们期望建模更深入的结果。
- 代谢组是离表型最近的组学，并且代谢物本身的含量就可以算一种表型，例如中药中某些代谢物是重要的药用成分，能够定位到代谢物关键影响的位点，对于改良重要提供高产的中药意义重大。代谢物相比测序而言，其成本和困难度更高，如果能实现直接预测，将可以imputation数据。
- 从多组学数据建模代谢物表达量的可行性，从宏观来看表型是由基因型和环境决定的，基因型是基础，环境是多变的，有的研究有将环境细分了田间管理，即三个因素决定表型。多组学建模中DNA代表着基因型，RNA是DNA转录的产物，其也是基因型的表现，另外也受到环境的影响，我们可以认为RNA是即具有基因型的信息又带有环境的信息，从宏观公式来看，基于DNA+RNA数据建模表型/代谢物是可行的。
- 代谢物是是多基因共同作用的产物，所以要引入网路或基因集的内容，网络和基因集需要从外部公共研究中引入或者其它
