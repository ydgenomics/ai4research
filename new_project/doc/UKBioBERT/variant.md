将群体遗传变异数据注入 DNA 基因组大模型（如 DNABERT-2、UKBioBERT 范式），并非直接将 VCF 统计矩阵或连续数值输入神经网络，而是通过“将真实单倍型序列转译 + 变异感知掩码策略”的机制，在持续预训练（Continue Pre-training）阶段注入模型。

结合研究文献与生物信息工程规范，其完整的注入技术细节与流程如下：

---

### 一、 变异数据的准备与个体化序列转译

#### 1. 变异数据的选择与过滤

* **变异类型**：核心选取**单碱基多态性（SNPs）**与**短插入缺失（Small Indels, < 50 bp）**。这两类变异数量最大且拥有精确的 1 bp 分辨率坐标。


* **结构变异过滤**：通常会过滤掉大片段结构变异（Large SVs > 50 bp、CNV、转座子），避免破坏基于参考基因组坐标系（如 TSS $\pm 100\text{ kb}$）的固定滑动窗口对齐。


* **群体遗传学质控 (QC)**：
* **MAF 过滤**：过滤掉次要等位基因频率 $\text{MAF} < 0.01$ 或 $< 0.05$ 的极稀有突变，防止低频噪声干扰模型。


* **HWE 过滤**：剔除偏离哈迪-温伯格平衡（Hardy-Weinberg Equilibrium, $p < 10^{-6}$）的位点，剔除测序错误。


* **缺失率**：丢弃缺失率（Missing Rate）$> 10\%$ 的位点。





#### 2. 个体化单倍型伪序列构建（Haplotype Sampling）

将群体 VCF 文件（如 UK Biobank 或 3K Rice 项目的百万级 VCF）与标准参考基因组（如 hg38 或 IRGSP-1.0）结合：

* 根据个体基因型（Genotype），把 VCF 中标注的 Alt（突变型）碱基动态替换到参考基因组的 Ref（参考型）相应物理坐标位置。


* 为每个个体构建出带有真实群体变异的**个体化单倍型 DNA 序列（Pseudo-genomes / Haplotypes）**，作为 Masked Language Model (MLM) 的输入。



---

### 二、 核心注入机制：变异感知掩码（Variant-Aware MLM）

标准的 DNABERT-2 采用掩码语言模型（MLM），以固定的概率（如 15%）随机遮挡 DNA Token 并要求模型进行预测。**注入变异的关键在于修改 Mask 的概率分布矩阵**：

```
[ 原始个体 DNA 序列: ... A  T  C  G  [G->A]  C  T  A  G ... ]
                                      │ (变异位点 & Motif 区域)
                                      ▼
             [ 概率偏置采样 (Variant-Aware Masking) ]
                                      │
                                      ▼
[ 被遮挡的 Token:   ... A  T  C  G    [MASK]   C  [MASK] A  G ... ]
                                      │
                                      ▼
                  [ 输入 DNABERT-2 Transformer 编码器 ]
                                      │
                                      ▼
          [ 损失计算: 强迫模型根据上下文恢复变异碱基与 Motif ]

```

1. **加权 Mask 策略 (Weighted Masking)**：
* 对序列中**不含变异**的常规背景区域，保持较低的随机 Mask 概率。


* 对**已知变异位点（Variant Sites）及其上下游相邻的 6–15 bp Motif 区域**，赋予显著提升的 Mask 采样权重（如提升 2~3 倍概率）。




2. **强制上下文学习 (Forced Contextual Representation)**：
* 当变异位点或关键 Motif 被 [MASK] 掩盖后，模型无法再机械地记忆参考基因组的固定文本。


* 强迫模型必须依赖变异位点两侧的远端上下文语义（Contextual Semantics）来反推被遮挡的碱基，从而迫使 Transformer 的注意力机制（Self-Attention）深度学习单碱基突变对局部调控语法的破坏。





---

### 三、 构建后的数据清洗与防护流程

伪序列生成并进行模型训练前/中，必须经过以下四步工程清洗，防止模型崩塌或数据泄露：

1. **模糊碱基（N）与缺失填充（Imputation）**：
* 采用 Beagle 5.4 或 Impute5 等工具对测序缺失位点进行高精度填充，确保单倍型完整度 $> 99\%$。


* 在提取特征窗口（如 100 kb 序列）时，若窗口内未知的模糊碱基 N 占比 $> 1\%$，直接丢弃该窗口。




2. **物理坐标对齐与移码修复 (Coordinate Standardizing)**：
* 插入/缺失（Indel）会拉长或缩短序列，破坏统一的物理坐标。
* **清洗策略**：在提取启动子或 TSS 窗口时，只对 SNP 做等长替换；对短 Indel 统一采用**固定填充（Padding with '-'）或尾部截断**的格式，强行将序列对齐为固定的上下文窗口长度（如固定 131,072 bp），确保后续与 1 bp 分辨率的信号追踪直接挂钩。




3. **严防连锁不平衡（LD）导致的训练数据泄露**：
* 由于染色体内物理相邻的变异存在极强的连锁不平衡（LD），绝对不能使用“随机采样（Random Split）”来划分训练集与测试集。


* **染色体隔离切割（Chromosome Splitting）**：
* **训练集 (Train Set)**：染色体 1–7（以水稻为例）或 1–16（以人类为例）。


* **验证集 (Validation Set)**：染色体 8–9 或 17–19。


* **测试集 (Test Set)**：染色体 10–12 或 20–22。


* 确保测试集染色体上的变异和基因表达 Tracks 在预训练与下游微调阶段完全处于未见（Unseen）状态。
